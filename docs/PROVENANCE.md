# Provenance

Drafty in this repository is new work for the Meta Global AI Developer Hackathon 2026, Indie / Push the Frontier track. The engineering package, API, studio, and CalculiX path were written for this event. They are not a continuation of an older application’s solver or database.

The wordmark in `apps/web/src/assets/logo.png` and `apps/web/public/logo.png` is the same image previously used by the 2025 Drafty project. It was copied here at the author’s request so the studio keeps that name and mark. Reuse of that asset, and of any earlier code that is not in this tree, still needs confirmation from the hackathon organizers. This file records the reuse; it does not claim that permission has already been granted.

No third-party solver output is stored as if it were a new result. CalculiX, Gmsh, CadQuery, and the other libraries keep their own licenses.
